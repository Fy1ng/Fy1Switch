# README artwork

- `app-icon.png` is a lossless, metadata-free copy of the existing Windows application icon at `src/windows/RemoteDisplaySwitch.Host/Assets/App.png`.
- `windows-light.png` and `windows-dark.png` are lossless, metadata-free copies of the isolated WPF renders in `artifacts/fluent-ui-20261021/`. The original renders use `IDesktopController.Simulation = true` with fixture devices and states. The dark render uses an injected palette. They show the application layout, not real hardware or an Android screenshot.
- `hero.zh-CN.svg` and `hero.en.svg` are original static illustrations made for Fy1Switch. They use project colors and simple monitor, phone and power shapes. They contain no remote assets, scripts or animation.
- The existing application icon and Fluent UI symbols retain their source provenance in [assets/README.md](../README.md) and the repository's third-party notices.
- Visual organization was informed by [beautify-github-readme](https://github.com/oil-oil/beautify-github-readme). No artwork from that repository was copied.

The SVGs are editable source files. README body text, commands and links remain Markdown.
