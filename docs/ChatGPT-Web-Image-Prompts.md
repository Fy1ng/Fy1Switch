# RemoteDisplaySwitch 图片素材批量生成提示词

适用日期: 2026-10-20. 面向 ChatGPT Web 的提示词包, 共 21 项: 14 项基础图标母版和 7 项可选插图及宣传素材. 本文件交付提示词, 不表示图片已经生成或接入.

## 1. 使用方式

1. 在 ChatGPT Web 新建一个支持图片生成的对话, 先发送下方的统一规则.
2. 发送 A01, 选定满意结果后将其作为本系列的品牌参考. 后续任务保留该参考; 更换对话时重新附上选定图片和统一规则.
3. 按编号逐条发送提示词, 每次生成一张独立图片. 一次粘贴整份清单不保证 Web 自动连续完成全部出图. 可以按品牌, 功能图标, 插图分别建对话并附参考图.
4. S01 选定后作为 S02-S05 的几何参考. U01-U07 保持同一线宽和视觉尺寸. 每完成一项, 下载原图并按表格命名.
5. 先完成基础素材, 再按实际需要生成可选素材. 所有插图均不含界面文案, 文案由应用或后期排版添加.

目标尺寸和格式是验收要求, 提示词不能保证 Web 精确输出. 下载后检查像素尺寸, 实际透明通道和边缘质量, 再进行缩放, 着色和格式转换. 图中画出的棋盘格不是真正透明背景.

## 2. 与当前项目的对应关系

- Windows 已有浅色和深色主题, 浅色强调色为 `#2D5CB4`, 深色强调色为 `#9EC3FF`.
- Android 已有动态配色, 固定配色回退为浅色 `#365BC1` 和深色 `#B2C5FF`. 品牌素材采用与现有界面协调的蓝色, 功能图标保持单色以供系统着色.
- Windows 托盘已有开启, 关闭和待确认三态. Android 快捷开关已有显示器开启, 关闭和刷新图形. 应用内还有显示器, 电源, 设置, 返回, 下拉, 添加, 确认和刷新八类图标.
- 基础包覆盖上述图形和品牌母版. 现有图标可继续使用; 生成母版不要求把现有矢量图标替换成位图.
- 引导插图和宣传图是可选扩展, 当前界面不依赖这些图片. 暂不为纯设置表单生成背景, 按钮贴图或装饰性状态图片.
- 配对二维码必须继续由程序根据当次配对数据生成. 不让图片模型生成可用二维码, 配对码, 凭据或真实界面截图.

当前依据: `DesktopTheme.cs`, `TrayIcons.cs`, Android 的 `AppIcon.kt`, `DisplayTileService.kt`, `RemoteDisplayScreen.kt`, `res/drawable/ic_display*.xml`, 以及 `docs/UI-Terminology.md`.

## 12. 出图检查

- 每个编号只有一个独立主体, 没有拼图, 标签, 水印或多余文案.
- 实际尺寸和比例经过检查, 透明素材确有 alpha 通道, 边缘没有白边和假棋盘格.
- A01 和 A02 是同一标志. S01-S05 的外框, 支架, 底座和占位一致. 功能图标的笔画与留白一致.

- 所有功能图标均试放浅色与深色背景, 托盘和快捷开关还需检查系统着色和高对比度表现.
- 插图没有反转配对方向, 没有真实配对信息, 没有把示意屏幕画成远程桌面功能.
- 所需图片选定后再进行资源转换和接入. 本提示词包不修改应用界面或资源实现.
