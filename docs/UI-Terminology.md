# 界面术语与交互约定

| 场景 | Windows | Android |
| --- | --- | --- |
| 已读到开启状态 | 显示器已开启 | 显示器已开启 |
| 已读到关闭状态 | 显示器已关闭 | 显示器已关闭 |
| 未获得可信状态 | 显示器状态待确认 | 显示器状态待确认 |
| 添加控制设备的入口 | 连接手机 | 添加电脑 |
| 开关操作 | 开启、关闭 | 开启、关闭 |
| 配对凭据 | 电脑二维码、电脑短码 | 扫描电脑二维码、电脑上的六位短码 |
| 保存过的授权 | 已授权手机 | 已配对电脑 |

应用内中文说明使用全角标点。协议字段、地址、端口和诊断码保持原格式。

短码统一由电脑显示、手机输入；手机输入六位有效数字后自动提交一次，失败后由用户修改或手动重试。二维码和粘贴备用配对信息仍可用。底层双向 SRP 协议保留兼容性，反向输入不再作为界面入口。

状态只来自已验证的设备响应。成功反馈短暂显示，警告保留到下一次相关操作。未知状态不允许切换；Android 快捷开关的未知状态点按仅刷新。

Windows 的手机列表显示授权时间，不把它称作最近连接时间。Android 的电脑列表区分最近连接成功、连接失败和待刷新；历史成功不代表当前在线。当前版本未新增持续在线探测、连接历史数据库或后台轮询。

Windows“连接手机”在主窗口内打开悬浮层，只显示二维码、六位配对码和必要的配对进度，不创建独立窗口。网络、手机控制开关、中继、已授权手机、自启动和诊断集中在主窗口独立“设置”按钮内。尚未启用手机控制时先进入设置，不会在打开浮层时保存未提交的设置。

手机控制设置默认自动识别局域网并显示网络与访问地址摘要, 自定义网卡、IP、HTTPS 端口及访问地址收在"高级设置". Tailscale 和中继默认仅显示启用开关, 开启后展开对应子表单. 地址检测与编辑只更新表单, 统一点击"保存连接设置"后应用; 关闭可选路径后保留其配置和已加密凭据. 备用配对信息复制也位于高级设置.

只有配对浮层可见时才续期自然过期的配对码。正在握手、配对失败、尝试次数耗尽或用户停止后不会自动重新认证。进程级累计限流不会因续期重置。关闭浮层、按 Esc、点遮罩、最小化、隐藏主窗口或锁屏时结束本次配对并撤销一次性凭据。设置中的备用复制由用户显式生成，不自动续期，离开设置时撤销。
